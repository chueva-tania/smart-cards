# 📚 Умные карточки

Тренажёр для 5 класса (программа московской школы). Два предмета — литература и русский язык,
переключаются кнопками наверху главного экрана. Структура: **предмет → тема → карточка**.
Один файл `index.html` — открывается двойным щелчком, работает без интернета, ничего не
нужно устанавливать. Прогресс хранится в самом браузере.

## Две механики вместо одной

**📝 Карточка-слово** — для имён, названий, дат. Чёрточки по числу букв видны сразу, ответ
проверяется точно, а буквы открываются **в хаотичном порядке**: не слева направо, а вразбивку.
Мозг не следит за появлением слова, а вспоминает его.

    Сразу    → _ _ _ _        (столько букв в ответе)
    Ошибка 1 → _ У _ _        (открылась вторая)
    Ошибка 2 → М У _ _        (первая)
    Ошибка 3 → М У _ У        (четвёртая)
    Ошибка 4 → М У М У        (третья — слово открыто целиком)

Когда открыты все буквы, появляется кнопка «Показать ответ». Карточка засчитывается только
если ответ введён правильно — показанный ответ в зачёт не идёт.

Порядок у каждого слова свой и всегда один и тот же. Для «МУМУ» и «ГЕРАСИМ» он задан
руками (`order: [2,1,4,3]` и `[3,1,5,2,6,4,7]`), для остальных слов считается сам —
по буквам слова, поэтому от запуска к запуску не меняется. Порядок никогда не совпадает
с обычным, слева направо.

**💭 Карточка-образ** — для вопросов «почему» и «зачем». Ответ пишется своими словами в
многострочном поле (отправка кнопкой или Ctrl/⌘+Enter). Область подсказок сначала пуста,
картинки приходят по одной, каждая следующая сильнее:

    Ошибка 1 → барыня сердито указывает на собачку
    Ошибка 2 → Герасим с камнем у реки
    Ошибка 3 → стрелка от барыни к реке — причина и следствие
    Ошибка 4 → кандалы: он не свободен
    Ошибка 5 → правильный ответ текстом (карточка не засчитывается)

Когда ключевое слово найдено, карточка не закрывается сразу: появляется «👍 Верно, но скажи
полнее» — поле остаётся активным, и ребёнок может дописать мысль. Кнопка «Готово, показать
ответ» завершает этап: только тогда карточка засчитывается и показывается полный ответ.
Если дописывать нечего — можно нажать сразу, ответ всё равно покажется и карточка зачтётся.

Предыдущие подсказки не исчезают: они остаются наверху маленькими, а свежая показывается
крупно — видно всю цепочку.

## Картинки

Картинки **не грузятся из интернета** — они нарисованы прямо в приложении вектором (SVG)
из деталей: человек, барыня, собака, река, кресло, кандалы, пушка, яма, шест, кукла,
Кремль, изба, стрелка причинно-следственной связи. Поэтому ничего не отваливается,
не требует хостинга и работает офлайн — с Google Диском и Postimages этой возни больше нет.

Если захочется поставить свою картинку, вместо функции достаточно вписать прямую ссылку:

    pics: [
      'https://example.com/barynya.jpg',   // внешняя картинка
      () => scene([ ... ])                 // нарисованная
    ]

## Предмет 2: русский язык

Одиннадцать тем; в каждой карточки-слова на термины и правила и одна карточка-образ на понимание.
Подсказки здесь не сценки, а разборы: слово с подчёркнутыми частями, ударение, вопрос в пузыре,
плитка с правилом.

| Тема | О чём | Карточек |
| --- | --- | --- |
| 🔤 Фонетика и графика | звуки, буквы, алфавит | 2 слова + 1 образ |
| 🗣 Орфоэпия | ударение и произношение | 2 + 1 |
| 🧩 Морфемика | состав слова | 3 + 1 |
| ❓ Правописание -тся/-ться | вопрос подскажет мягкий знак | 2 + 1 |
| ь Мягкий знак после шипящих | ночь, но мяч | 2 + 1 |
| ❕ Синтаксис и пунктуация | словосочетание, знаки | 2 + 1 |
| 📕 Лексика | синонимы и антонимы | 2 + 1 |
| 🔀 Корни с чередованием | -кас-/-кос-, -лаг-/-лож- | 2 + 1 |
| 🔉 Приставки на -з/-с | звонкая или глухая | 2 + 1 |
| ✅ Безударные гласные в корне | проверяй ударением | 3 + 1 |
| 📦 Падежи существительных | вопросы и окончания | 3 + 1 |

Всего 36 карточек: 25 слов и 11 образов, 44 подсказки. Ответы вроде «ЕСЛИ В ВОПРОСЕ ЕСТЬ Ь»
принимаются и коротко — «что делать», «есть мягкий знак».

  где больше двух ошибок или которые ещё не взяты; в этот же фильтр попадают произведения
  с прогрессом ниже 50%. Трудные можно гонять сразу по всем произведениям.

### Что хранится в localStorage

Ключ `smartcards.v2`, на каждую карточку три поля:

| Поле | Смысл |
| --- | --- |
| `attempts` | сколько раз нажимали «Проверить», включая удачный раз |
| `correct` | `true`, если карточка взята правильным ответом |
| `hintsUsed` | сколько подсказок открылось в последнем заходе |

«Выучено» на прогресс-баре — это число карточек с `correct: true`.
- **Ввод**: Enter или кнопка «Проверить». Enter работает и дальше — переход к следующей карточке.
- **Проверка слова** не придирается к регистру, пробелам, точке в конце и не различает «е» и «ё».
  Описка в одну букву в длинном слове засчитывается как верный ответ — с показом правильного написания.
- **Итог**: сколько карточек взято с первой попытки, список того, что стоит повторить,
  и кнопка «Повторить трудные».
- **Общий прогресс** «Выучено X из Y карточек всего» — строкой над фильтрами.
- **Прокрутка**: на главном экране заголовок, общий прогресс и фильтры закреплены, а список
  произведений прокручивается сам — колесом мыши, полосой прокрутки и тач-жестами. Пока внизу
  есть ещё карточки, нижний край списка растворяется; на очень низком экране (меньше 420px)
  прокрутка отдаётся всей странице.

  Высота списка задана двумя ограничителями: `max-height` по высоте экрана и жёсткий потолок
  560px. Второй нужен для встраивания в iframe без собственной прокрутки (просмотрщик
  артефактов): там `100dvh` равен высоте всего кадра, а не видимой области, и без потолка
  список растягивался бы на весь кадр — прокручивать было бы нечего, а шапка уезжала вверх.
- **Прогресс** сохраняется между запусками. Кнопка «Сбросить прогресс» спрашивает
  подтверждение в отдельном окне.
- Тёмная и светлая тема — как в системе. Экран подстраивается под телефон и компьютер,
  текст не мельче 16px, кнопки синие, неактивные — серые, поле ввода при ошибке краснеет.
  Буквы появляются за 0,3 с (scale), картинки — за 0,4 с (fade-in).

## Как добавить свои карточки

Литература — в разделе «ЧАСТЬ 2. КАРТОЧКИ», русский язык — в «ЧАСТЬ 2Б». Предметы собираются
в конце второго раздела:

    const SUBJECTS = [
      { id:'lit', emoji:'📖', title:'Литература',   works: WORKS },
      { id:'rus', emoji:'✏️', title:'Русский язык', works: RUSSIAN }
    ];

Новый предмет — это ещё один такой блок со своим массивом тем. Новая карточка-слово:

    { id:'mumu-w12', type:'word', q:'Вопрос?', a:'ОТВЕТ', alt:['ещё вариант'] },

`order` можно не писать — хаотичный порядок посчитается сам. Карточка-образ:

    { id:'mumu-i5', type:'image', q:'Почему…?', a:'Правильный ответ текстом.',
      keywords:['барыня', 'приказ', 'крепостной'],
      pics:[ () => scene([...]), 'https://…', () => scene([...]), () => scene([...]) ] },

`keywords` — обычные слова в начальной форме. Как проверяется ответ:

1. текст разбивается на слова по пробелам и знакам препинания;
2. выбрасываются стоп-слова — предлоги, союзы, частицы, местоимения («и», «в», «на», «что», «она»…);
3. каждое оставшееся слово приводится к основе, поэтому «барыней», «барыня» и «барыне» — одно и то же;
4. если хотя бы одно слово совпало с ключевым — ответ верный.

Детали для картинок лежат в разделе «ЧАСТЬ 1. РИСОВАНИЕ ПОДСКАЗОК».

Новое произведение — это ещё один блок в `WORKS` с `id`, `emoji`, `title`, `author` и `cards`.

## Запуск

Открыть `index.html` двойным щелчком. Чтобы гонять карточки с телефона, файл можно
положить в любой веб-хостинг или открыть по локальной сети:

    python3 -m http.server 8777

и зайти с телефона на `http://<адрес-компьютера>:8777/`.
