# Вспоминалка — публичный сайт

[https://vspominalka.ru](https://vspominalka.ru) — описание iOS-приложения, интерактивный
пример и браузерный тренажёр. Статические HTML/CSS/JavaScript размещаются в GitHub Pages
из корня ветки `main`. Домен задан файлом `CNAME`.

## Содержимое

| Файлы | Назначение |
|---|---|
| `index.html`, `landing.css` | Описание функций приложения, предметов, классов и подключения |
| `media.js` | Адреса растровых иллюстраций сайта в File Storage |
| `demo.js` | Три карточки по «Муму»: выбор букв и два ответа своими словами |
| `demo-engine.js` | Сгенерированный движок и правила проверки ответов примера |
| `trener/index.html` | Сгенерированный браузерный тренажёр 5 класса |
| `assets/logo-umnik.svg` | Векторный знак интерфейса |
| `docs/image-storage-manifest.json` | Исходные имена перенесённых файлов, ключи объектов, размеры и SHA256 |
| `support.html`, `privacy.html` | Поддержка и описание обработки данных |

Снимок полного каталога **iOS-приложения** на 27 октября 2026 года: **5788 карточек,
438 тем, 8 предметов, классы 2–7**. В 2–4 классах доступны русский язык, математика,
литературное чтение, окружающий мир и английский; в 5–7 — литература, русский язык,
математика, география, биология и английский.

Браузерный тренажёр использует часть этого каталога: **1372 карточки, 73 темы, шесть
предметов 5 класса**. Открыты первые две темы каждого предмета и темы, переданные ссылкой
`#id`; остальные обозначены как доступные в приложении. На главной отдельный пример
из трёх карточек, без регистрации и сохранения результата.

## Изображения и данные

Растровые иллюстрации находятся в File Storage на IMS-4 (SeaweedFS/S3, бакет `smartcards`).
Иллюстрации сайта используют префикс `illustrations/web-v1/`; соответствие исходным
путям и проверенные хеши записаны в `docs/image-storage-manifest.json`.
Сайт загружает картинки через API `/api/v1/files/{ключ}`. В базе сервера находятся только
относительные ключи объектов, без домена и бакета; реквизиты S3 браузеру не передаются.
Перенесённые растровые файлы не хранятся в репозитории сайта. Архивные источники
основного банка карточек сохраняются в закрытом префиксе `sources/` Storage.

Веб-страница проверяет ответы локально. Пример на главной работает в памяти вкладки;
браузерный тренажёр сохраняет прогресс и настройки в localStorage. Его очистка удаляет
локальные результаты. Изображения требуют сети при загрузке; гарантированный режим
без сети для браузерного сайта не заявлен.

Новые версии приложений iOS и Android требуют соединения с сервером, в том числе для гостевых
занятий. Темы и картинки загружаются по запросу без постоянного кэша. Сервер управляет
прогрессом аккаунта; после действия приложение ждёт подтверждения сохранения и
приостанавливает занятие при сбое. Гостевой прогресс сохраняется локально. Отчёты
устройства отправляются только после согласия и не заменяют прогресс аккаунта.

## Подготовка движка и тренажёра

`demo-engine.js` и `trener/index.html` собираются из исходников банка карточек и движка;
вручную их не редактировать:

```bash
python3 ../smartcards-android/tools/build_web.py --demo
python3 ../smartcards-android/tools/build_web.py --site
```

Правила примера находятся в `smartcards-ios/tools/understanding/demo/`, описание формата —
в `smartcards-ios/tools/understanding/README.md`. Если меняются вопрос или образец ответа
в `demo.js`, пересобираются правила, затем выполняется проверка соответствия.
Изменение пути изображения не меняет вопрос, ответ или порядок подсказок.

При изменении JavaScript обновляется `?v=` у соответствующего скрипта в `index.html`,
чтобы браузеры загрузили новую версию. CSS-разметка и содержимое демонстрационных карточек
изменяются отдельно от переноса файлов в Storage.

## Локальный просмотр и проверки

```bash
python3 -m http.server 8778 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8778/`. Для растровых картинок нужен доступ к серверному API.

Проверка трёх карточек главной страницы против общего движка:

```bash
node ../smartcards-ios/tools/tests/js/demo.js .
```

Проверяются исходный движок, отпечатки правил, образцы, допустимые и неверные ответы,
отрицания и уточнения. Остальные проверки движка находятся в iOS-проекте.
Перед публикацией проверяются ссылки, интерактивный пример и отображение на узком экране.

## Публикация

```bash
git push origin main
```

GitHub Pages публикует корень `main`; `CNAME` сохраняется в коммите. Завершение push
подтверждает отправку исходников, а готовность сайта проверяется отдельно по результату
Pages и содержимому [vspominalka.ru](https://vspominalka.ru).

Публичная ссылка установки iOS на сайте не размещена. Сборки TestFlight выпускаются из
[smartcards-ios](https://github.com/chueva-tania/smartcards-ios); API, админка и Storage
описаны в [smartcards-backend](https://github.com/chueva-tania/smartcards-backend).
