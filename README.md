# Вспоминалка — сайт

Публичный лендинг: https://vspominalka.ru. Статические HTML/CSS/JS, без сборки.

- `index.html`, `landing.css`: описание приложения и фактического покрытия классов.
- `demo.js`: три демонстрационные карточки «Муму». Ввод обрабатывается в памяти вкладки, без отправки ответов и сохранения результата. Проверка образов использует ключевые основы, не полноценную семантическую оценку.
- `assets/`: оригинальные иллюстрации из приложения; имена файлов стабильны.
- `trener/index.html`: переход со старого адреса на новый пример. Прежний тренажёр сохранён в истории Git.
- `privacy.html`, `support.html`: описание данных и поддержка.

Локальный просмотр: `python3 -m http.server 8778 --bind 127.0.0.1`.

Каталог на 24.09.2026: 2 822 карточки, 7 предметов. Литература 5–7; русский и математика 4–5; география и биология 5; литературное чтение и окружающий мир 4. При изменении бэкенда цифры и покрытие на сайте нужно обновлять.

Проверено в браузере: слово с ошибкой и правильным ответом, подсказки-иллюстрации, дополнение ответа, показ объяснения без зачёта, завершение примера. При ширине 390 px горизонтального переполнения нет, ошибок JS не обнаружено. Платёжных функций и публичной ссылки установки пока нет.
